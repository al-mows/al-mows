# Gallery photos

Add real before-and-after job photos here, named to match the entries in
`src/data/gallery.ts`, for example:

- project-1-before.jpg / project-1-after.jpg
- project-2-before.jpg / project-2-after.jpg
- project-3-before.jpg / project-3-after.jpg

Recommended: landscape photos, roughly 4:3, optimised to JPG/WebP.
If a file is missing, the gallery shows a labelled "photo to be added"
placeholder rather than a broken image.
